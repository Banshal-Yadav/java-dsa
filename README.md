# Java DSA

Data Structures & Algorithms practice in Java.

## Topics
- Java Basics — variables, datatypes, input/output, typecasting
- Operators & Control Flow — loops, switch, break/continue
- Patterns — star, number, character patterns
- Functions — methods, binomial coefficient, recursion
- Number Systems — binary/decimal conversion, prime, sieve
- Arrays — searching (linear, binary), subarrays, Kadane's, 2D arrays
- Hash Maps & Sets — HashMap, HashSet, ArrayList operations
- LeetCode — curated problem solutions (Arrays, Strings, 2D Matrices)
